    Requirements

    What you need before installing. To put it together, go to Fast installation.

    What you need

    ComputerRaspberry Pi 4 (this is what the rig was built and measured on)
    SurfaceNative Instruments Maschine MK2, over USB
    AudioNothing extra required. The Pi's own headphone output works, and every figure in this project was measured on it at 48 kHz. An external interface Zynthian supports is optional and will sound better — but it is not what any of this was tested against
    StorageSD card, 16 GB or more — the ZynthianOS image is about 7.5 GB compressed
    DisplayAny HDMI monitor or TV for Zynthian's own UI, driven with a USB mouse and keyboard. A touchscreen is what the instrument was built around and is far nicer to play, but it is not required to install. You do need a screen eventually: saving snapshots happens there and nowhere else
    NetworkThe Pi must reach the internet during installation
